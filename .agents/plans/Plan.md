# Plan: UI and UX improvements for Nimendra's Notes

## Goal

Keep the homepage's personal To/From memo voice while making it a useful starting point: explain what is here, show the main topics as visible cards, and offer a clear path to a note. Then improve navigation and reading on desktop and mobile, followed by visual polish. Keep the existing Quartz site, theme, and publishing boundary.

## Decisions

- **Homepage first, then site-wide polish.** Retain the original To/From memo greeting and sign-off while making top-level topic cards visible without expanding callouts, with one clear browse/search path. Keep recently updated notes as the existing dynamic second path. Prefer explicit destinations and clear reading cues to more animation or another persistent dashboard.
- **Use existing Quartz plugins and the homepage template.** Do not fork packaged Search, Explorer, or Graph plugins in this pass; first improve their placement, labels, and surrounding guidance. Quartz incorrectly marks generated folder routes as broken, so exempt only the verified homepage topic cards in the local `link-notice` plugin; leave other broken-link notices intact.
- **Restore the existing homepage Graph rather than add a second graph.** Remove the homepage-only hide rule and dead homepage-Graph styling, then verify the existing sidebar Graph and full-graph trigger are reachable on desktop and mobile. This avoids duplicate heavy graph rendering. If mobile still cannot reach the trigger, provide a visible link/route using supported plugin behavior in a follow-up.
- **Treat hover previews as optional.** Keep linked note titles and search results usable with keyboard and touch; no information should be available only on hover.
- **Keep the current Catppuccin identity.** Correct broken tokens and measured contrast before adjusting decoration. Do not replace the theme or add dependencies.
- **Give tags a subtle, theme-aware chip style.** Use soft Latte surfaces with darker readable text in light mode and soft Macchiato surfaces with lighter text in dark mode. Keep one consistent chip treatment across inline tags, listings, note properties, and tag pages; do not assign arbitrary colors to individual tag names. Maintain the `#` marker and distinguish hover, focus, and active states without relying on color alone.

## Scope

In scope: homepage information architecture and responsive presentation, Graph visibility, keyboard/mobile navigation affordances, text and focus contrast, reduced motion, custom tag-chip theming, and restrained visual consistency. Out of scope: changing vault publication rules, rewriting Quartz or third-party plugins, replacing the design system, and adding analytics or new content categories.
